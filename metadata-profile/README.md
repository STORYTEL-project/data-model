The metadata profile was slightly modified and expanded to meet the project needs, mainly for archival purposes and basic domain-related searches.  
The JSON file is compiled through a combination of automatic pipeline processes and manual researcher input. It is divided into four sections reflecting the event-creation structure of the STORYTEL ontology:

```json
{
  "full_video": { … },
  "full_video_creation": { … },
  "story": { … },
  "story_creation": { … }
}
```

`full_video` and `full_video_creation` replace the previous single `video` section, distinguishing between the properties of the digital object itself and the properties of the recording event that produced it - consistent with the `Full_Video` and `Full_Video_Creation` classes in the ontology. Similarly, `story_creation` is kept separate from `story` to reflect that clipping is a distinct event carried out by a different actor at a different time from the original recording.

This metadata profile re-uses already existing standards, in particular [Dublin Core Terms](http://purl.org/dc/terms/), [Schema.org](http://schema.org/) and [DataCite](https://datacite-metadata-schema.readthedocs.io/en/4.7/).

The **Compilation** column indicates how each field is expected to be populated:

- `AUTO` — set automatically by the pipeline; no human input required
- `AUTO (conditional)` — set automatically based on the value of another field
- `AUTO (LLM)` — generated by a language model from manually specified parameters
- `MANUAL` — must be filled in by the researcher

The **Automation Source** column describes the specific process or tool used to populate each field.

The **Visibility** column indicates whether the field is exposed to end users:

- `public` — visible to all users
- `private` — internal only; not exposed in the public interface

The **Visibility Rationale** column provides the reason for the visibility choice, using the following categories:

- *Searchability* - needed for users to find and filter resources
- *Research corpus description* - contextualises the recording for scholarly use
- *Internal governance* - administrative or compliance metadata not relevant to end users
